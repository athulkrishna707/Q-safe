# Q-SAFE: Zero-Trust API Security Gateway — Setup & Operating Guide

Welcome to **Q-SAFE** (Query-Sequence Authorization & Forensic Enforcement). This document provides step-by-step instructions for running, testing, and demonstrating the entire system.

---

## 🏗️ Architecture Overview

Q-SAFE consists of two main components operating together:

```
┌─────────────────────────────────────────────────────────────┐
│                    Q-SAFE Security Stack                    │
│                                                             │
│  ┌─────────────────────────┐   Vite Proxy   ┌─────────────┐ │
│  │   React / TS Frontend   │───────────────▶│ Python API  │ │
│  │     (Port 3000)         │                │ (Port 8000) │ │
│  └─────────────────────────┘                └─────────────┘ │
│               │                                    │        │
│    Interactive Dashboard                    FastAPI Gateway │
│   - Live Threat Feed                        - CCFH Engine   │
│   - AI Threat Oracle                        - BFLA / BOLA   │
│   - Sequence Visualizer                     - Rate Limiter  │
│   - Attack Launcher Modal                   - Profiler & AI │
└─────────────────────────────────────────────────────────────┘
```

- **Backend (Python 3.12+ / FastAPI / Uvicorn)**: Runs on `http://localhost:8000`
- **Frontend (React / Vite / Tailwind)**: Runs on `http://localhost:3000` *(requests automatically proxy to port 8000)*

## 🎯 How to Demonstrate Q-SAFE

Once both services are running:

### 1. Baseline Ambient Traffic
The dashboard's **Live Gateway Traffic Feed** will automatically populate with benign mixed traffic (from simulated users `alice`, `bob`, and `admin`) generated by the backend every ~2 seconds.

### 2. Launch Simulated Attacks
- Click the floating **"Simulate BFLA Attack"** button at the bottom-right of the dashboard, OR navigate to the **Attack Matrix** tab.
- Choose any attack preset:
  - **BFLA (Privilege Escalation)**: User `alice` attempts to invoke `DELETE /admin/users/bob`.
  - **BOLA (Object Ownership Theft)**: User `alice` attempts to access `bob`'s bank account `B-2002`.
  - **Rate Abuse**: 200 rapid-fire requests from a single session.
  - **Token Replay**: Replayed or expired JWT attempt.

### 3. AI Forensic Inspection
- Click on any **BLOCKED** request in the live stream.
- Inspect the **AI Threat Oracle** panel on the right:
  - **Bitwise Hash Delta**: Visualizes `(Hash_Prev << 1) ^ Endpoint_ID`.
  - **OWASP Category**: E.g., `OWASP API5:2023 (BFLA)`.
  - **MITRE ATT&CK Mapping**: E.g., `T1134 (Privilege Escalation)`.
  - **Quarantine Action**: Click **"Quarantine Session Context"** to immediately invalidate all future requests from that session ID.

## 🛠️ Troubleshooting

### Issue 1: `pip : The term 'pip' is not recognized`
Run pip using the python module flag:
```powershell
python -m pip install -r requirements.txt
```
Or use the pre-configured MSYS2 Python path:
```powershell
C:\msys64\ucrt64\bin\python.exe -m pip install -r requirements.txt --break-system-packages
```

### Issue 2: `npm : File ... npm.ps1 cannot be loaded because running scripts is disabled`
This is caused by Windows PowerShell ExecutionPolicy. Run `npm` via `cmd`:
```powershell
cmd /c "npm run dev"
```

### Issue 3: OpenRouter AI Key (Optional)
If no `OPENROUTER_API_KEY` is provided, Q-SAFE automatically uses high-precision local deterministic templates so the demo **always functions offline**.
To supply a custom key, create a `.env` file inside `qsafe_backend/`:
```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
```
